GitHub Monitor 1.3.0 (เวอร์ชัน Python)
=======================================

โปรแกรมดูยอดเข้าชม, ยอด clone, เว็บที่ส่งคนเข้ามา และยอดดาวน์โหลดไฟล์ใน Release ของ repo บน GitHub
เก็บประวัติไว้ในเครื่อง (GitHub เก็บยอดเข้าชมย้อนหลังให้แค่ 14 วัน)
ใช้ Python 3.6 ขึ้นไปที่มีอยู่ในเครื่อง เช่น Anaconda ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

ติดตั้ง
------
1. แตกไฟล์ zip (คลิกขวา > Extract All)
2. ดับเบิลคลิก install.cmd
   ถ้า Windows ขึ้นหน้าต่างถามยืนยันก่อนเปิดไฟล์ ให้เลือกเปิด (Run)
   ถ้าเปิดไม่ได้: เปิด Anaconda Prompt พิมพ์ python แล้วเว้นวรรค ลากไฟล์ github_monitor.py มาวาง
   เว้นวรรค พิมพ์ --install แล้วกด Enter
3. โปรแกรมจะติดตั้งที่ %LOCALAPPDATA%\Programs\GitHub Monitor สร้างไอคอนบน Desktop และ Start Menu
   แล้วเปิดหน้าจอเป็นแท็บในเบราว์เซอร์
4. ครั้งแรกให้สร้าง GitHub token ตามขั้นตอนบนหน้าจอ แล้ววาง token

ติดตั้งเสร็จแล้วลบโฟลเดอร์ที่แตกจาก zip ได้เลย
ติดตั้งเครื่องอื่น: ก๊อป zip ไปทำขั้นตอนเดิม แล้ววาง token อีกครั้ง
(token เข้ารหัสผูกกับบัญชี Windows ของแต่ละเครื่อง ก๊อปข้ามเครื่องไม่ได้)

ใช้งาน
-----
- เปิดจากไอคอน GitHub Monitor บน Desktop หน้าจอเปิดเป็นแท็บในเบราว์เซอร์ ปิดแท็บแล้วโปรแกรมปิดตาม
- โปรแกรมดึงข้อมูลใหม่ให้เองตอนเปิด (ถ้ารอบล่าสุดเกิน 6 ชั่วโมง) หรือกด "อัปเดตตอนนี้"
- ตั้งค่า > "เปิดเก็บอัตโนมัติทุกวัน" ให้ Windows ดึงข้อมูลวันละครั้งตอน 09:00 น. (ไม่บังคับ)
- เลือก repo และช่วงเวลา (14 / 30 / 90 วัน / ทั้งหมด) ได้ที่แถบตัวกรอง กราฟแต่ละอันกด "ตาราง" เพื่อดูตัวเลขรายวันได้
- กดชื่อ repo ในแผงด้านบนเพื่อดูกราฟของ repo นั้น
- สลับภาษาไทย/อังกฤษได้ที่ปุ่ม "ไทย | EN" มุมขวาบน โปรแกรมจำภาษาที่เลือกไว้ใช้ครั้งต่อไป
  (Switch between Thai and English with the "ไทย | EN" buttons at the top right.)

ถอนการติดตั้ง
-----------
ตั้งค่า > ถอนการติดตั้ง

อัปเดตเป็นเวอร์ชันใหม่
-------------------
แตกไฟล์ zip ของเวอร์ชันใหม่ แล้วดับเบิลคลิก install.cmd ซ้ำ ข้อมูลประวัติและ token เดิมยังอยู่ครบ

สำหรับผู้ดูแลระบบ (IT)
--------------------
- เป็นสคริปต์ Python ไฟล์เดียว (github_monitor.py) อ่านโค้ดได้ทั้งหมด ใช้แค่ไลบรารีมาตรฐานของ Python
- ต่ออินเทอร์เน็ตเฉพาะ https://api.github.com แบบอ่านอย่างเดียว ด้วย token ของผู้ใช้
- เปิดเว็บเซิร์ฟเวอร์เฉพาะที่ 127.0.0.1 พอร์ตสุ่ม ทุกคำสั่งต้องมีรหัสสุ่มของรอบนั้น
- ไฟล์โปรแกรม: %LOCALAPPDATA%\Programs\GitHub Monitor
- ข้อมูล: %LOCALAPPDATA%\GitHubMonitor (token เข้ารหัสด้วย Windows DPAPI)
- ไอคอน: Desktop และ Start Menu ของผู้ใช้
- งานตามเวลา (เฉพาะเมื่อผู้ใช้กดเปิดเอง): Task Scheduler ชื่อ "GitHub Monitor Daily"
- ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ และไม่แก้ไขอะไรบน GitHub
